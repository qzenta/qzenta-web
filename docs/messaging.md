Qzenta operates across three distinct capability pillars:
1. **Digital Infrastructure:** Production websites, managed hosting, domain lifecycle management, cloud integrations, and ongoing technology stewardship.
2. **Intelligent Automation:** Autonomous AI agents, business process automation, orchestrated n8n workflows, and resilient system integrations.
3. **Business Software:** Modern accounting technology, payroll and HR software, integrated business management applications, and specialized SME solutions.

Our flagship software products — **Qzenta Accounting** and **Qzenta Payroll** — are currently in active engineering and private development, representing our long-term commitment to providing African SMEs with purpose-built, high-reliability business software.

## 3. Operational Services vs. Products in Development

To protect brand credibility, uphold truth in advertising, and comply with strict consumer trust standards, Qzenta enforces an unambiguous boundary between **available operational services** and **products in development**.

```
+-------------------------------------------------------------+-------------------------------------------------------------+
| OPERATIONAL SERVICES                                        | PRODUCTS IN DEVELOPMENT                                     |
| (Available Now / Commercially Active)                       | (In Engineering / Pre-Release)                              |
+-------------------------------------------------------------+-------------------------------------------------------------+
| - Digital Infrastructure (Web, Hosting, DNS, Cloud)         | - Qzenta Accounting                                         |
| - Managed Technology Services                               | - Qzenta Payroll & HR                                       |
| - Custom Intelligent Automation & n8n Workflows             | - Integrated SME Application Suite                          |
| - Dedicated AI Agent Systems & Integration                  | - Proprietary ERP Modules                                   |
+-------------------------------------------------------------+-------------------------------------------------------------+
| Mandatory Phrasing & Terminology:                           | Mandatory Phrasing & Terminology:                           |
| - "Deployed and managed end-to-end"                         | - "Currently in active engineering"                         |
| - "Production-grade infrastructure available now"           | - "Product in development — private alpha roadmap"         |
| - "Engage directly with our engineering team"               | - "Register for roadmap updates / early access preview"     |
| - "Operational delivery within structured milestones"       | - "Designed to integrate seamlessly upon release"           |
|                                                             |                                                             |
| Prohibited Terminology:                                     | Prohibited Terminology:                                     |
| - Do not state "instant off-the-shelf software"            | - NEVER use "Buy now", "Sign up today", "Instant login"    |
| - Do not claim unverified SLA guarantees                    | - NEVER present software as live, operational, or in market |
| - Do not refer to software products as commercially live    | - NEVER fabricate user counts, screenshots, or testimonials |
+-------------------------------------------------------------+-------------------------------------------------------------+
```
